⚙️ How It Works

From Panic to Pin
in 4 Steps

1

Victim Starts a Voice Call

Opens AeroRescue in browser. No typing, no forms — speaks naturally in any panicked state.

2

Universal-3 Pro Transcribes in Real-Time

AssemblyAI converts noisy, breathless emergency audio to text with sub-second latency.

3

LLM Tool Calling Extracts Location & Type

The Voice Agent LLM parses the conversation, derives GPS coordinates, and fires the dispatch_rescue_team tool.

4

Live Rescue Pin Drops on the Map

A Leaflet map instantly shows the victim's exact location — coordinators dispatch rescuers immediately.

🛠️ Technology Stack

Built on World-Class
AI Infrastructure

Core AI
🎙️ AssemblyAI Voice Agent API
End-to-end STT → LLM → TTS pipeline over a single WebSocket. Uses Universal-3 Pro for transcription and built-in LLM tool calling.
Interactivity
🔧 JSON-Schema Tool Calling
The dispatch_rescue_team tool fires client-side when the LLM extracts enough context, sending lat/lng to the frontend.
Mapping
🗺️ Leaflet + OpenStreetMap
Renders a live interactive rescue map that populates rescue pins instantly when the tool call fires over the WebSocket.
Backend
🐍 Python + FastAPI
Secure token server for ephemeral WebSocket auth, plus a LeMUR batch endpoint for post-call transcript analysis.
